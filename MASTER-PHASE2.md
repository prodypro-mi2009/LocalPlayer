## Design decisions / limits you should know
- Default library = everything MediaStore lists. SAF-granted folders are indexed IN ADDITION (their URIs are document URIs; playback and tag
  writing use the folder's persisted read/write grant). A file that MediaStore also lists is not added twice (same folder + file name).
- A folder playlist is a mirror: songs can't be added/removed by hand until it is unlinked (message explains).
- Playlist folder sync re-runs after each library scan; files that appear in a folder that MediaStore does not index are only picked up if
  the folder was added to the library (this happens automatically when the playlist is created and files were missing).
- Hiding the song that is playing skips to the next one (Media3 behaviour of removing the current item); Now Playing closes so the Undo is visible.
- Under Shuffle, Media3 places inserted items in its own order, so "Play next" is exact only with shuffle off (unchanged from Phase 1).
- Undo of removing the CURRENT queue entry puts it back at its old index but does not resume it.
- SAF cannot pick a storage root or the Download folder on Android 11+ (Android restriction); such a pick shows a clear message.
- Songs grid cards have no swipe gestures (unchanged).
